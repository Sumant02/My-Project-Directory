# My Project Directory

This is a Python project stored in `d:\Learn\AI Engineer\My Project Directory`.

## Setup

Activate the virtual environment in PowerShell:

```powershell
cd "d:\Learn\AI Engineer\My Project Directory"
.\.venv\Scripts\Activate.ps1
```

## Notes

- Python environment is stored in `.venv`
- Ignore `.venv` and editor files with `.gitignore`
